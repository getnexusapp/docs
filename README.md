# Nexus Docs

Public documentation for [Nexus]().

## Structure

- `getting-started/` — installation, first launch, account/setup
- `notes/` — folders, tags, wiki-links, version history, markdown syntax
- `browser/` — tabs, bookmarks, downloads
- `assistant/` — connecting an API key, how grounding/search works, privacy
- `graph/` — reading and navigating the knowledge graph
- `settings/` — themes, data export/backup, clearing data
- `faq/` — common questions
