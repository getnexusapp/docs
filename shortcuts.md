# Keyboard Shortcuts

## Global

| Shortcut | Action |
|---|---|
| `Ctrl / Cmd + K` | Open the Command Palette |
| `Esc` | Close the current dialog, modal, or palette |

The Command Palette (`Ctrl/Cmd + K`) is the fastest way to move around Nexus — jump to any note by fuzzy-searching its title, create a new note or folder, or switch between the Notes, Browser, Assistant, and Graph tabs, all without touching the mouse. With nothing typed, it leads with your pinned and most recently edited notes.

> Note: while focus is inside the Browser tab's native page view, global shortcuts like `Ctrl/Cmd + K` won't be picked up — that's a native browser webview, not part of the rest of the app's keyboard handling.

## Command Palette

| Shortcut | Action |
|---|---|
| `↑` / `↓` | Move selection |
| `Enter` | Run the selected item |
| `Esc` | Close |

## Note Editor

| Shortcut | Action |
|---|---|
| `Ctrl / Cmd + B` | Bold |
| `Ctrl / Cmd + I` | Italic |
| `Ctrl / Cmd + U` | Underline |
| `Ctrl / Cmd + Z` | Undo |
| `Ctrl / Cmd + Y` (or `Shift + Ctrl/Cmd + Z`) | Redo |

Undo/redo groups by whole word, not by keystroke or by sentence — one step reverts one word at a time.

## Quick Capture

| Shortcut | Action |
|---|---|
| `Esc` | Cancel and close |
| `Ctrl / Cmd + Enter` | Save as a new note |

The first line you type becomes the note's title; everything after the first line break becomes the body.
